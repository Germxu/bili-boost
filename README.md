<h1 align="center">Bili Boost</h1>

<p align="center">一个让 B站 更好用的 Chrome 扩展。</p>

## 功能

- **评论区 IP 属地显示**：在评论日期旁显示发布者的 IP 属地。
- **滚轮倍速播放**：鼠标悬停在播放器的「倍速」按钮上滚动即可调速，右键恢复 1x。
  - 范围 0.25x–5x；2x 内每档 0.05x，2x 以上每档 0.3x。
  - 只拦截倍速按钮上的滚轮，不影响 B站 原生的音量滚轮。
  - 开启「记住倍速」后，速度自动保存，打开新视频也会保持。
- **视频帧读取**：点播放器左下角时间戳旁的相机按钮，或点 popup 的「截取当前帧」，把当前画面保存为 PNG，文件名是 `视频标题_视频内时间点.png`。无需开关，装好即可用。
- **沉浸式进度条**：视频画面底部常驻一条细进度线，不用动鼠标也能看到播放进度；原生控制栏出现时自动隐藏，不遮挡操作。无需开关。

> 顶部导航自定义：规划中。

## 安装

### 直接加载（推荐）

仓库的 `dist/` 目录已包含构建好的产物，可直接使用：

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择仓库中的 `dist/` 目录。

### 从源码构建

需要 Node.js 环境（建议 20+）。

```bash
npm install
npm run build
```

构建产物在 `dist/`，按上面方式加载即可。

## 使用

- 点击工具栏的扩展图标打开 popup，开关功能、设置倍速、截取当前帧。
- 「评论区 IP 属地显示」首次启用后，刷新视频页生效。
- 调速时把鼠标放到播放器控制条的「倍速」按钮上滚动；右键该按钮恢复 1x。
- 截图无需开关：点播放器左下角时间戳旁的相机按钮，或点 popup 的「截取当前帧」。

> 注意：在 `chrome://extensions` 重新加载扩展后，需要刷新已打开的 B站 页面，旧页面的脚本才会被替换。

## 开发

```bash
npm run dev        # 开发模式
npm run typecheck  # 类型检查
npm run build      # 生产构建
```
